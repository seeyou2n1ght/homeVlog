# 性能与质量基准

## 验收口径

比较必须固定数据库快照、人工标签、展示时间轴、分辨率、帧率、音频策略和编码配置，并区分仅渲染与含分析的全流程。壁钟与累计 worker 工时分别报告；GPU 利用率不能直接换算为提速潜力。当前成片配置为 1920×1080、20fps，不是保留源素材 4K。

人物识别规则变化必须通过独立人工 holdout；模拟脚本硬编码的 100% recall 不能作为证据。输出验收至少覆盖音视频轨、时长、拼接边界连续解码、目标播放器和代表性画质检查。
