# HomeVlog 产品需求规格说明书 (PRD)

HomeVlog 是一套针对海量家庭安防监控视频执行智能浓缩处理的离线批处理系统。本产品基于 Intel i5-12600K (UHD 770 QSV) 与 NVIDIA RTX 3060Ti (NVENC/CUDA) 异构计算架构，利用多线程流式管线与硬件加速技术，剔除无效静态画面并无缝拼接运动事件，最终生成连贯且高画质的单日监控浓缩 Vlog。

# 1. 产品范围与业务目标


系统定位于解决家庭监控设备产生的大量长尾视频带来的存储与检索成本问题。其核心业务路径包含 NAS 挂载路径自动嗅探、按天与摄像头维度的任务分组、双层视觉检测与极速渲染。最终产物必须为包含原声音轨与原始时间戳的连贯 MP4 文件，静态时段采用极速快进过渡，动态时段采用一倍速原画放映。

# 2. 核心功能需求

## 2.1 任务调度与元数据探针
- 系统针对指定的 SMB 父级目录（如 `\\192.168.5.8\LyuShare`）进行扫描，利用正则匹配识别符合 `XiaomiCamera_<index>_<MAC>` 规则的底层设备目录。
- 引擎读取 YAML 配置文件中预设的 `MAC地址: 场景别名` 映射表，将物理设备地址转化为强可读的场景标识。
- 最终生成的浓缩视频严格采用以“场景别名”为主干文件夹、日期为最终文件名的分类拓扑（如 `output/living_room/Vlog_living_room_20260321.mp4`），便于按物理位置进行历史演变追溯。

## 2.2 视觉过滤与语义验证
- 预筛模块按照极低频抽样率执行画面对比，若无明显差值则将文件判定为全局静态并绕过深层分析。
- 能量计算模块基于 OpenCV 运行高斯滤波与帧间像素差分计算，识别局部画面的动态潮汐能量。
- 语义验证模块通过 PyTorch 执行目标检测，当能量差触发特定阈值时核实是否包含预设物理实体。

## 2.3 硬件加速与渲染管线
- 时间轴切片器生成包含状态属性的时段集合，为静态片段施加指令快进缩放。
- 渲染引擎强制附加缓冲池限制与时间戳生成参数，挂载构建完成的长文本滤镜图谱执行输出。
- 渲染出口端附加恒定帧率对齐滤镜，根除主流播放软件解析此类混合时间轴时发生的解码死锁故障。

# 3. 非功能与工程架构需求

## 3.1 极限硬件算力分配
- 计算集群运用 Python 多进程模块启动相互隔离的软解与预筛工作区，阻断全局解释器锁的算力争抢损耗。
- 推理集群采用生产者消费者模型，独立显卡独立承接异步存疑帧队列的批量矩阵推理运算。
- 硬件编码器受制于并发锁约束，溢出渲染任务将被路由分发至中央处理器的内置硬件流水线。

## 3.2 容错容灾机制
- 核心引擎必须捕捉视频破损、文件截断造成的解码器异常，丢弃坏帧并持续拼接剩余可用片段。
- 探测环节严格执行异步输入输出隔离，防范网络传输抖动引发的主线程内核态阻塞假死。
- 极大能量差跳过机制允许系统在面临剧烈像素变动时直接赋予动态标记，拦截非必要的模型开销。

## 3.3 编码与构建规范
- 工程整体构建与包管理强制依托独立环境工具实现底层运行库的版本锁定与全局隔离。
- 底层核心算法模块及业务函数要求具有完备的静态类型注解与边界条件防御异常捕捉。
- 可观测追踪体系基于现代日志框架构建，日志存储依照文件体积与警告级别执行物理滚动切分。
