# HomeVlog 性能基准与优化追踪 (Performance Benchmark History)

本文档记录 HomeVlog 系统在基准硬件配置下的历次全量测试性能指标演进与优化收益。

## 基准测试环境
- **CPU**: Intel Core i5-12600K (6P + 4E, 16 线程)
- **iGPU**: Intel UHD Graphics 770 (双 Gen12 VDBox)
- **dGPU**: NVIDIA GeForce RTX 3060Ti (8GB GDDR6, NVENC + NVDEC + Tensor Core)
- **测试素材**: 	estsample/ 下 84 个 2026-09-01 真实 4K H.265 监控视频切片 (原始时长: 21.07 小时 / 75,837 秒)

## 阶段细分与关键指标追踪

### 1. 硬件利用率与物理架构演进
- **异构协同全双工解耦**：物理实测证实，Intel UHD 770 的双 Gen12 VDBox 负责 8 路 4K 硬件解码可达峰值吞吐（84 个文件仅用 84 秒搞定预筛）；而一旦强行让核显同时承担复杂滤镜图的 `hevc_qsv` 编码，其共享内存总线与驱动会发生严重拥塞。最终定型架构将 UHD 770 确立为 Decode-Only，RTX 3060Ti 确立为 Inference & Dual-NVENC Encode-Only，实现零争抢满负荷全双工。
- **内核级死锁彻底清零**：排查并消除了包含 66 个输入流与高阶多项式变速滤镜的复杂批次中，匿名管道（64KB buffer）写满引发的 `subprocess` 写挂起死锁，采用临时文件异步落盘与零拷贝技术彻底解决。
- **进度条时间可读性**：彻底消除跨阶段计时脱节问题，清晰输出 [渲染实耗: MM:SS | 预估余时: MM:SS | 均速 Xs/批]。
