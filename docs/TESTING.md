# 测试与验收

当前结果见[验收报告](ACCEPTANCE.md)。测试围绕仍交付的子系统组织；训练、调参、基准、旧脚本和固定实验观察的专用用例已退役。人工审核优先回归迁入test_review_regression.py。

## 执行

先跑受影响专项，跨模块裁剪通过后跑一次全库；没有新变更或未解失败不重复跑数，不把专项与全库通过数累加。使用现有uv/CUDA环境，不替换PyTorch。

```powershell
uv run ruff check main.py src scripts tests
uv run python -m compileall main.py src scripts
uv run python -m pytest tests/
```

tests/conftest.py隔离生产DB、输出、缓存、归档和日志。本地真实FFmpeg小媒体按工具可用性运行；GPU专项须显式开启HOMEVLOG_HARDWARE_TESTS，不为代码裁剪自动重跑硬件或历史整日。

## 保留的验收路径

| 范围 | 保护行为 |
| --- | --- |
| 扫描/持久化 | 懒解析、完整发现、零字节与不可访问区分、部分失败恢复 |
| 分析/预筛 | 灰度合同、迟到短事件、完成度、保守阴性、未知停止不得启动第二读者 |
| 时间轴/人工审核 | 共享展示计划、整数帧/样本、精确源区间、持久审核/撤销和重分析覆盖 |
| 并发/生命周期 | 原许可恰好一次归还，未知停止保留原许可；Job/线程终态及跨日期认领 |
| 渲染/恢复 | 软件FFmpeg像素/时钟/音频；完整接缝、失败/取消不完成、旧交付保持、事务回滚/骤停恢复 |
| 工作台 | 全库存分页/范围、迟到响应、原片播放、审核归因、重渲缓存和视觉相似索引 |
| 日常版 | 当前DB/人工审核、确定性预算、完整父帧去向、混合裁决、冲突/陈旧预览、取消/重复启动和发布身份 |

日常capture集成控制核对人工阳性/阴性改变快照及选择；真实软件媒体覆盖非零父原点、非关键帧裁剪、首尾/接缝和整数AV时钟。真实HTTP控制核对退役页面/API为404。
UI修改还使用隔离DB和2秒合成媒体做实际浏览器检查，核对队列、保留菜单、配置归因和控制台错误，不冒充家庭原片识别或完整成片验收。
