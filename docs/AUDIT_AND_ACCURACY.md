# HomeVlog 算法准确度审计与人机复核规范 (Accuracy Audit & Review Specification)

本文档归纳 HomeVlog 在复杂家庭环境下的识别质量基准、5 类疑难样本判定规则、人工复核流转契约与安全微调规范。

---

## 一、算法识别质量基线 (Quality Baselines)

HomeVlog 基于多模态融合（EMA 运动显著性 + 8x8 空间网格滤波 + AudioEnergyVAD + YOLO 流式微批推理）对全天监控进行动静切片，其核心质量基准如下：

| 评估维度 | 衡量指标 | 目标基准 | 实现保障 |
| :--- | :--- | :--- | :--- |
| **切片拓扑完整度** | 连续同状态未合并碎片对数 | **0 对 (0.0%)** | YOLO 判定后强制触发 `_merge_same_state()` 二次拓扑熔断 |
| **置信度数据闭环** | YOLO 动态段零置信度占比 | **0.0%** | 推理得分实时双向回填 `Segment.avg_confidence` |
| **误报抑制 (FP)** | 疑似光影刚性动态段占比 | **< 1.0%** | 8x8 空间网格连通域能量集中度门限 + YOLO 目标存在性验证 |
| **漏检抑制 (FN)** | 婴儿房微光漏检率 | **趋近 0%** | 暗光自适应阈值下调 (0.4x) + 动态间歇前后缓冲 (pre/post-roll) |
| **极短抖动控制** | $< 2.0\text{s}$ 眨眼跳跃切片数 | **0 个** | 拓扑平滑窗口 `apply_smoothing: true` 自动吸收 |

## 二、主动学习 5 类疑难切片判定规则 (Anomaly Categories)

数据库接口 `VlogDatabase.get_anomaly_segments()` 按照以下规则从海量切片中自动挖掘待复核疑难切片：

1. **疑似光影假动态 (`fp_suspect`)**:
   - 条件：`state == 'DYNAMIC'` 且 `avg_confidence == 0.0` 且 `max_energy < 8.0`。
   - 物理成因：日落斜射、汽车远光灯扫过地面或白平衡自适应跳变，引起画面大面积亮度变化，但无真实人员或宠物存在。
2. **疑似动作漏检 (`fn_suspect`)**:
   - 条件：`state == 'STATIC'` 但能量接近门限或存在 `BORDERLINE_MICRO_MOTION` 标记。
   - 物理成因：婴儿在暗光红外微光下缓慢翻身或微小动作，差分能量处于临界值（3.5~5.0）。
3. **多模态冲突 (`multimodal_conflict`)**:
   - 条件：视频画面判定为静态，但音频分析触发 `DYNAMIC_AUDIO`（如咳嗽、哭声、物体落地声）。
   - 物理成因：画外音、视线盲区声音事件或空调底噪瞬态抖动。
4. **置信度临界 (`borderline_confidence`)**:
   - 条件：YOLO 目标置信度徘徊在判定门限边缘（0.25 ~ 0.35）。
   - 物理成因：远距离极小目标、遮挡目标或姿态异常人体。
5. **极短状态抖动 (`jitter`)**:
   - 条件：切片时长 $< 2.0\text{s}$ 且与前后切片状态频繁翻转。
   - 物理成因：树影摇曳或光照临界频繁震荡。

## 三、人工复核流转与反向纠偏契约 (Review Workflow)

1. **工作台交互打标 (`scripts/audit_tool`)**:
   - 审核员通过 Web 工作台查看双轨时间轴（算法轨 vs 人工轨），调用 4 秒快照预览或关键帧 Lightbox 进行判定。
   - 打标结果通过 `/api/segment_review` 原地持久化到 `segments` 与 `human_reviews` 表。

2. **时间轴反向纠偏机制**:
   - 当切片被人工标记为 `FALSE_ALARM`（误报）或 `STATIC`：在渲染时间轴构建时**强制降级为纯静态抽帧段**，彻底消除成片中的无效噪点。
   - 当切片被人工标记为 `MISSED_ACTION`（漏检）或 `DYNAMIC`：在渲染时间轴构建时**强制提升为常速动态段**，挽救关键家庭瞬间。

## 四、安全微调数据集导出与训练防退化规范

1. **正负样本平衡导出 (`scripts/export_dataset.py`)**:
   - 审核通过的真动态样本导出为 YOLO 标准标注（归一化坐标与类别）。
   - **强制负样本导出**：确认的纯静态段（TN）与误判段（FP）强制导出为空 txt 标注文件，使模型明确感知“空旷客厅/婴儿床”属于无目标背景。

2. **冻结骨干网络微调 (`scripts/train_yolo.py`)**:
   - 微调启动参数强制包含 `freeze=10`，仅更新检测头权重，冻结前 10 层通用骨干特征提取网络。
   - 严禁在小样本机位微调中进行全量参数更新，防止骨干特征退化导致泛化虚警爆炸。
