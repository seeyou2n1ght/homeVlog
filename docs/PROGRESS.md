## 物理极限与硬件特性深刻发现 (Empirical Insights)

1. **GA104 单 NVDEC 引擎的物理硬顶**:
   RTX 3060Ti 仅有 1 个物理 NVDEC ASIC。若分析端分配 3 路 NVDEC，在渲染阶段与 2 路 NVENC（同样依赖 NVDEC 解码）并发时，共 5 个进程时间片竞争单个解码器，导致大动态批次（如 `batch_1`）解码饥饿，耗时从 188s 暴增至 326.5s。因此在 2 NVENC 并发时，`max_nv_decoders: 2` 为绝对物理甜点（2 分析 + 2 渲染 = 4 路上限）。
2. **Intel UHD 770 异构窃取的算力衰减边界**:
   UHD 770 拥有 32 EUs。对于 <=180s 的中轻度动态批次，其能保持 2.5x~3.5x 实时倍率并分担 40+ 分钟动态素材；但对于 >200s 的重动态批次（如 `batch_0`），其编码速度跌至 1.8x（耗时 107.2s），而 NVENC 仅需 42.2s（5.0x）。因此，动态窃取必须配置队列余量平滑衰减，在收尾阶段将长动态批次强制留给独显收口。
3. **异步前瞻预分期 (Lookahead Pre-staging) 的纯正收益**:
   后台 Worker 将全部 142 个切片的预读取前置在分析中盘全部完成，彻底消除了 GPU 渲染线程在 SMB 慢速网络上的 100+ 秒串行等待。
4. **理论物理极限收敛**:
   全天 302.9 分钟动态素材，双路 NVENC 满载纯算力下限为 ~15 分钟壁钟；叠加分析重叠中盘（T+16.5m 完成）及首尾排队与合流，**25 分钟左右即为此套硬件配置（i5-12600K + RTX 3060Ti + UHD 770）的渐进物理极限**。当前系统的 25m55s 距离绝对理论下限误差小于 5%。
