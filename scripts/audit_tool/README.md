# 人工复核工作台

使用 `uv run python scripts/audit_tool/app.py` 启动。可复核片段分类、观看带声音的原片区间、查看当前机位配置和共享展示计划，并按日期/机位重渲。J/K用于切换审核项；播放器打开时暂停盲打标签。保存须等服务器确认。

队列支持全库存分页、筛选、精选及固定种子随机抽查。视觉相似只表示整体画面近似，不表示相同事件或已审核；界面显示实际索引覆盖，可为当前源补建索引。索引帧/短动图不替代完整区间和声音复核。

“配置与归因”中的复核依据逐条记录观看范围：未记录、代表图、完整视频、完整视频与可用声音、仍不能确定。快捷和批量裁决保留每条已有依据，不把一条的观看声明复制给其他片段。新冻结准确度样本时，活动阳性须声明看过完整视频，活动阴性须同时核对可用声音；其余裁决仍用于人工覆盖，但参考值为未知。声明不证明盲性、场景或事件独立；留出集和四场景组数门禁另行检查。旧冻结数据不自动改写，此字段不生成目标框训练真值。

重渲前可查看批次计划及缓存命中；失败/取消保留旧交付和有效批次。实际成片对比只使用已验证的媒体映射，无映射的旧成片不反推定位。

参数比较只消费匹配当前代码、配置、模型、依赖和完整源身份的生产重放收据。没有实测则显示未测；同配置差值必须为0。误报/漏检库存与识别准确度不同，场景参考不足时不自动应用参数，也不从能量分位数给出未经测量的阈值推荐。

报告中的全部参考F1用于诊断比较。独立验收明细另显示留出参考、四场景事件组数量及要求、未用于验收的原因和缺失/失败场景；缺失字段显示“未知”。调优记录不会被删除，但不能充当留出验收；同一事件的多个窗口不增加独立样本量。门禁未通过时应用按钮保持隐藏，读取失败会清除上次计数与收益。

事件审核和目标框复核分开：误报/静止不证明画面没有人、猫或狗。工具菜单的“当前归档帧：人工目标框”支持画框、人物/猫/狗类别、选中删除及清空；完整保存须明确检查全部可见目标，另可保存草稿或不能确定。旧归档来源不能核验时，先复核事件，再显式重新生成原片归档帧。生成图片会读取原片；打标只针对当前固定图片，不改变事件分类或成片。生成新帧不会继承旧图目标结论。

训练导出门禁只接受绑定图像SHA、捕获源身份/时刻且完成全部目标复核的 `.targets.json`；明确无目标才允许空框。草稿、不能确定、旧txt、事件标签和模型自动预测不作为人工真值。目标保存使用来源快照及记录版本拒绝陈旧覆盖，旧记录保留到target_history；旧save_bbox接口写出的txt不能直接用于训练。

菜单“导出YOLO数据集”创建新的导出目录，不覆盖旧导出、不自动重建归档或启动推理/训练。默认训练/调优/留出约60/20/20，固定种子42：同日期原片跨机位保持同组，未知日期按原片路径，相同图片连接来源组并去重，冲突标注排除。不足三个有效组或缺少完整复核时提示未就绪。实际比例按整组分配；dataset_split.json记录划分、excluded_items.json记录排除原因。

训练入口核对导出清单、图片/标签SHA、文件集合与配置路径，拒绝旧未核验数据集。数据准备通过不等于模型准确度验收；独立测试、模型推广和可靠性故障验收另行执行。

训练每次使用独立目录，只导出本轮best权重；已有候选路径不覆盖，请显式指定新的`--output-model`。候选旁`.training.json`记录基底、数据与产物身份；失败或中断保留独立尝试记录，不借旧best/last成功。`--dry-run`只检查数据和基底文件，不加载模型或验证训练环境。

已有候选可用`uv run python scripts/train_yolo.py --data 导出目录/data.yaml --base-model 原基底.pt --evaluate-model 候选.pt --validation-data 导出目录/data.yaml`评估独立test分组；同一次导出中的train/val不得与test来源或图片重叠。报告按实际目标类别分别比较，保留每次独立评估目录。目标图片测试通过仍需原片动作/声音与生产阈值验收；`--apply`已停用，训练或图片评估不会切换生产模型。
