# HomeVlog 人机协同审核工作台 (Audit Tool)

本目录提供基于 Web 的本地切片复核与人机协同主动学习工作台，用于快速审查算法识别争议切片（TP/FP/FN/TN）、进行高清局部微距比对、触发秒级局部重新浓缩，以及将人工判定样本归档至训练集。

---

## 1. 本地启动方式

在项目根目录下通过 `uv` 运行：

```powershell
uv run python -m scripts.audit_tool.app
```

默认启动后访问本地地址：
```text
http://127.0.0.1:8000
```

---

## 2. 快捷键盲操速查表 (Action Hotkeys)

工作台支持全键盘盲操，按键后自动提交打标、异步归档代表帧、时间轴同步染色并**平滑居中聚焦下一个切片**：

| 按键 | 对应动作 | 业务影响 | 联动效果 |
| :---: | :--- | :--- | :--- |
| **`1`** | **确认有效动态 (TP)** | 算法判定正确，保留高清常速播放。 | 标记 TP ➔ 异步归档 ➔ 绿色高亮 ➔ 自动聚焦下一切片 |
| **`2`** | **纠偏为光影误报 (FP)** | 纠正假阳性，在成片中降级为静态快进。 | 标记 FP ➔ 异步归档 ➔ 红色高亮 ➔ 自动聚焦下一切片 |
| **`3`** | **纠偏为微动漏报 (FN)** | 挽救遗漏微动，在成片中提级为常速播放。 | 标记 FN ➔ 异步归档 ➔ 蓝色高亮 ➔ 自动聚焦下一切片 |
| **`4`** | **确认纯静止 (TN)** | 确认空镜纯静态，维持超高倍速略过。 | 标记 TN ➔ 异步归档 ➔ 灰色底色 ➔ 自动聚焦下一切片 |
| **`J` / `↓`** | **下一个切片** | 顺序检阅下一个争议样本。 | 焦点下移 ➔ 时间轴居中展开 ➔ 刷新三联帧 |
| **`K` / `↑`** | **上一个切片** | 回溯检阅上一个切片。 | 焦点上移 ➔ 时间轴居中展开 ➔ 刷新三联帧 |
| **`Space`** | **动图微视频预览** | 调起当前切片的 10fps WebP 动态剪辑。 | 弹出 Modal 循环播放短视频动图 |
| **`Y`** | **YOLO 强化画框** | 针对当前切片峰值时刻运行目标检测。 | 峰值卡片呈现检测框与类别置信度标签 |
| **`Esc`** | **关闭所有浮层** | 退出 Lightbox、动图预览或控制面板。 | 焦点重置回主工作台 |

## 3. 模块组织架构

```text
scripts/audit_tool/
├── app.py          # FastAPI / Uvicorn Web 服务器入口与 REST 路由
├── service.py      # 后台服务层：SQLite 查询、FFmpeg 抽帧管道、FrameArchiver 联动
├── rerender.py     # 局部重浓缩触发引擎 (调用 StreamingOrchestrator 执行秒级成片)
└── static/         # 前端 UI 资产
    ├── index.html      # 主页面模板
    ├── style.css       # 暗黑质检工坊主题样式 (Dark Studio)
    ├── app.js          # 前端交互引擎 (双层联动时间轴、三联画廊、盲操事件流)
    └── prototype.*     # 原型试验页面 (仅用于交互实验)
```
