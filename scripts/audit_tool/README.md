# 人工复核与观看工作台

从仓库根运行 `uv run python scripts/audit_tool/app.py`，打开打印的本地地址。默认端口8765，可用 `--port`修改，`--no-browser`不自动打开浏览器。

## 事件复核

队列支持日期/机位/状态/场景、字面搜索、隐藏已审、完整分页、精选、固定种子抽查及视觉相似。精选仅代表当前实际项；视觉相似表示画面近似，不等于同事件或已审核。可为当前原片补建派生索引。

J/K切换；两键或四键提交事件标签；U撤销当前区间审核。快捷/批量更新保持各项原有归因，不复制一条的观看声明到其他片段。保存以服务器确认和队列刷新为准。
“配置、归因与对比”只读展示全局/机位配置及共享计划的分析/人工覆盖差异，可保存事件标签、场景、备注和观看依据；不提供配置应用、模型训练或参数收益推断。

原片播放器按当前区间1.0倍速播放、保留原声并在区间末暂停。三张代表图不能证明整段无人；声音触发也不等于已识别具体声音事件。审核标签库存不作为独立准确率。

“成片版本对比”使用交付绑定的映射与审核历史，读取和播放核对身份；旧交付无映射时不反推定位。重渲先预览批次和缓存决策，再开始；取消须等待工作线程退出。失败保持旧交付、有效批次和恢复资产。

## 日常版

输入YYYYMMDD日期与机位，先“预览计划”，再“生成日常版”。同一快照重复请求复用任务；快照变化须重新预览。COMPLETED才表示完成，CANCELLING不是停止确认。

默认最多20分钟，选择完整父映射段，不裁断优先段。当前持久人工阳性优先；阴性相交段供复核；算法候选按半小时源时钟组轮询。优先内容超过预算返回BUDGET_CONFLICT。日常选择不重新分析、不替换完整成片、不写人工标签或主流程完成状态。

包内包含daily.mp4、selection.json、review.json、manifest.json，保存全部父帧去向、争议库存及双向定位。日常版可播放/下载，完整版本和相交段绑定父成片；正常速度原声回看依赖原片。清单只读，实际裁决需回实时队列核对，不能将冻结segment_id套到新分段。

必须保留完整四文件、绑定的父片及同目录meta和可访问原片。身份按路径/大小/mtime核对，不能检测保持相同stat的替换；包不是完整离线原片复核包。需要重新生成时还须有匹配的分析DB及人工审核数据。

当前历史观看包与其scratch父片均已移除，旧版本编号不再是可用交付。先由主流程生成完整成片，再预览新日常版；本轮没有自动重跑历史日期。

可用 `--watch-parent-root`选择独立父片目录；同日同机位多个父片会拒绝模糊选择。`--watch-output`修改观看包输出根。`--db`仅修改工作台数据库；它不会隔离重渲输出与其他运行路径，不能单凭此选项认定整个实例已隔离。

旧原型、目标框画布/智能体目标建议、数据集导出、基准管理、参数仿真和配置写入API已移除。现有归档图片、人工事件标签和来源记录保持，项目不自动训练或切换模型。
