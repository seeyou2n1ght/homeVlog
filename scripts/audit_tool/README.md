# HomeVlog 人机协同审核工作台 (Audit Tool)

本目录提供基于 Web 的本地切片复核与人机协同主动学习工作台，用于快速审查算法识别争议切片（TP/FP/FN/TN）、进行高清局部微距比对、交互式 BBox 漏检画框、触发秒级局部重新浓缩、生成参数调优建议，以及一键导出用于 YOLO 模型微调的训练数据集。

---

## 1. 本地启动方式

在项目根目录下通过 `uv` 运行（基于 Python 标准库 `http.server`，无需额外安装第三方 Web 框架）：

```powershell
uv run python scripts/audit_tool/app.py [--port 8765] [--no-browser]
```

启动后默认在浏览器中打开本地地址：
```text
http://127.0.0.1:8765
```

## 2. 快捷键盲操速查表 (Action Hotkeys)

工作台支持全键盘盲操，按键后自动提交打标、异步归档真实代表帧、时间轴同步染色并**平滑居中聚焦下一个切片**：

| 按键 | 对应动作 | 业务影响 | 联动效果 |
| :---: | :--- | :--- | :--- |
| **`1`** | **确认有效动态 (TP)** | 算法判定正确，保留高清常速播放。 | 标记 TP ➔ 异步归档 ➔ 绿色高亮 ➔ 自动聚焦下一切片 |
| **`2`** | **纠偏为光影误报 (FP)** | 纠正假阳性，在成片中降级为静态快进。 | 标记 FP ➔ 异步归档 ➔ 红色高亮 ➔ 自动聚焦下一切片 |
| **`3`** | **纠偏为微动漏报 (FN)** | 挽救遗漏微动，在成片中提级为常速播放。 | 标记 FN ➔ 异步归档 ➔ 蓝色高亮 ➔ 自动聚焦下一切片 |
| **`4`** | **确认纯静止 (TN)** | 确认空镜纯静态，维持超高倍速略过。 | 标记 TN ➔ 异步归档 ➔ 灰色底色 ➔ 自动聚焦下一切片 |
| **`J` / `↓`** | **下一个切片** | 顺序检阅下一个争议样本。 | 焦点下移 ➔ 展开时间轴 ➔ 刷新三联关键帧 |
| **`K` / `↑`** | **上一个切片** | 回溯检阅上一个争议样本。 | 焦点上移 ➔ 展开时间轴 ➔ 刷新三联关键帧 |
| **`B`** | **BBox 框选标注** | 进入/退出漏检人物鼠标框选模式。 | 激活画布 ➔ 拖动鼠标拉框 ➔ 生成 YOLO 侧边 txt |
| **`U`** | **撤销复核打标** | 清空当前切片的人工标签与场景归因。 | 重置标签 ➔ 刷新混淆矩阵与时间轴状态 |
| **`Y`** | **YOLO 强化画框** | 针对当前切片峰值时刻运行目标检测。 | 峰值卡片呈现检测框与类别置信度标签 |
| **`Space`** | **动图微视频预览** | 调起当前切片的 10fps WebP 动态剪辑。 | 弹出 Modal 循环播放短视频动图 |
| **`Esc`** | **关闭所有浮层** | 退出 Lightbox、动图预览、弹窗或标注模式。 | 焦点重置回主工作台 |

## 3. 核心功能与主动学习工作流

### 3.1 场景归因标签 (Scenario Attribution)
针对误报（FP）与漏报（FN），支持打标结构化场景：
- **光影刚性 (`LIGHT_SHADOW`)**: 白天阳光直射窗棂位移、车灯白墙反射；
- **车灯直射 (`HEADLIGHT`)**: 夜间汽车大灯扫过室内；
- **窗帘晃动 (`CURTAIN`)**: 空调风或穿堂风吹拂窗帘边缘；
- **婴儿微动 (`INFANT_MOTION`)**: 婴儿床上微弱肢体动作、呼吸或啼哭；
- **弱光夜视 (`DARK_ROOM`)**: 红外低照度黑白画面微动；
- **宠物活动 (`PET`)**: 猫狗地面跑动或跃起。

归因标签结构化保存至数据库 `segments.review_notes`，不破坏现有数据库 Schema，同时无缝被调优建议引擎解析。

### 3.2 交互式 BBox 漏检画框 (Interactive Annotation)
针对 YOLO 漏检的弱小目标（FN）：
1. 按快捷键 **`B`** 或点击峰值卡片上的 **`✏️ 标注 (B)`** 按钮；
2. 鼠标左键按住拖拽框选漏检人物；
3. 点击 **`💾 保存标注`** 或直接按数字键 `1~4` 打标，系统自动以归一化 `class_id xc yc w h` 格式生成同名 `.txt` 标注文件至 `data/feedback_archive/images/`；
4. 彻底解决后续构建数据集时因极低置信度无法自动生成框而导致正样本被丢弃（`excluded: -1`）的问题。

### 3.3 一键导出 YOLO 训练集 (Active Learning Dataset Export)
点击顶部 **`🏷️ 导出 YOLO 数据集`** 按钮：
- 自动划分 `train` 与 `val` 数据集（默认 8:2）；
- 导出完整的 `images/`、`labels/` 与 `data.yaml` 配置；
- 包含人工标注正样本与抑制光影虚警的**困难负样本（0 目标空标注文件）**；
- 弹窗内一键复制本地训练指令：
  ```bash
  uv run python scripts/train_yolo.py --data data/yolo_dataset/data.yaml
  ```

### 3.4 算法量化调参建议 (Settings.yaml Insights)
点击顶部 **`💡 调优建议`** 按钮：
- 自动统计已复核样本库的混淆矩阵、FP 误报能量分布、FN 漏报能量分布；
- 结合当前 `config/settings.yaml` 配置，生成量化调优推荐（如将 `detection.min_motion_threshold` 上调至 FP 能量的 75 分位点、将微弱夜视目标的 `yolo.confidence` 降至 0.20、微调 `segment.min_motion_duration` 等）。

## 4. 模块组织架构

```text
scripts/audit_tool/
├── app.py          # Python 标准库 http.server Web 服务器入口与 REST API 路由
├── service.py      # 后台服务层：混淆矩阵统计、FFmpeg 抽帧管道、BBox 导出、调优建议计算
├── rerender.py     # 局部重浓缩触发引擎 (调用 StreamingOrchestrator 执行秒级成片)
└── static/         # 前端 UI 资产
    ├── index.html      # 主页面模板 (科技感暗黑质检工坊 Dark Studio)
    ├── style.css       # 响应式布局、双层联动时间轴、BBox 画布、调优建议卡片样式
    ├── app.js          # 前端交互引擎 (双层联动时间轴、三联画廊、BBox 鼠标交互、盲操事件流)
    └── prototype.*     # 原型试验页面 (仅用于交互实验)
```
